## 1. 将网站数据备份至GitHub
[CSDN 参考文章](https://blog.csdn.net/u012195214/article/details/72721065)   
[使用hexo，如果换了电脑怎么更新博客？](https://www.zhihu.com/question/21193762)  

### 1.1 具体操作:
#### 1.1.1 情况1, 新建博客
+ 创建仓库: http://username.github.io
+ 创建两个分支: `master` 与 `hexo`（hexo 分支：保留源码（markdown、配置、主题等）master 分支：自动接收部署的 HTML）
+ 设置 hexo 为默认分支(原始文件，只需要手动管理这个分支上的Hexo网站文件)
+ 使用
  ```bash
  git clone git@github.com:username/username.github.io.git  # 拷贝仓库
  ```

+ 在本地 http://username.github.io文件夹下通过Git bash依次执行
  ```bash
  npm install hexo -g
  hexo init
  npm install
  npm install hexo-deployer-git # 此时当前分支应显示为hexo
  ```

+ 修改`_config.yml`中的deploy参数, 分支应为master;
+ 依次执行
  ```bash
  git add .
  git commit -m "XXXX"
  git push origin hexo # 提交网站相关的文件
  ```

+ 执行`hexo g -d`生成网站并部署到 GitHub 上

#### 1.1.2 情况2, 已经有部分博文部署到git但没有备份分支
+ 创建 hexo 分支, 并设置为默认分支
+ `git clone git@github.com:username/username.github.io.git`到本地, 删除除了 .git 以外的文件;
+ 复制原有的博客源文件, 注意除了`.deploy_git`, 并创建 `.gitignore`
  ```bash
  .DS_Store
  Thumbs.db
  db.json
  *.log
  node_modules/
  public/
  .deploy*/
  ```

+ 然后执行 
  ```bash
  git add .
  git commit -m "add hexo branch" 
  git push
  ```

### 1.5 Git Hook 配置

#### 1.5.1 Server端配置
```bash
# 安装 git 和 nginx
sudo yum install -y git nginx

# 启动 nginx 并设置开机自启
sudo systemctl start nginx
sudo systemctl enable nginx
```

```bash
# 创建 blog 用户
sudo adduser blog
# 设置密码（或者直接用 SSH 密钥免密，下面会讲）
sudo passwd blog

# 把仓库和网站目录的所有权交给 git 用户
sudo chown -R blog:blog /var/repo
sudo chown -R blog:blog /var/www/blog

# 裸仓库目录（接收 git push）
sudo mkdir -p /var/repo
# 网站目录（nginx 实际读取的文件）
sudo mkdir -p /var/www/blog

# 初始化裸仓库，--bare 表示创建一个裸仓库，不包含工作目录
cd /var/repo
sudo git init --bare blog.git
```

#### 1.5.2 配置 Git Hook 自动部署
```bash
sudo vim /var/repo/blog.git/hooks/post-receive

#!/bin/bash
# 原理：每次收到 push，就把最新代码 checkout 到 /var/www/blog，Nginx 直接读这个目录。
#!/bin/bash
git --work-tree=/var/www/blog --git-dir=/var/repo/blog.git checkout -f master
sudo chmod +x /var/repo/blog.git/hooks/post-receive

# 配置SSH免密登录
# 本地 Windows/Mac/Linux 都行（如果已经有Github密钥可以复用）
ssh-keygen -t rsa -b 4096
# 一路回车，生成 ~/.ssh/id_rsa 和 id_rsa.pub

# 本地执行
ssh-copy-id blog@你的服务器IP
# 或者手动操作：把本地 ~/.ssh/id_rsa.pub 内容追加到服务器 /home/blog/.ssh/authorized_keys

# 手动操作
# 切换到 git 用户
sudo su - git
mkdir -p ~/.ssh
chmod 700 ~/.ssh
vim ~/.ssh/authorized_keys
# 把本地 id_rsa.pub 的内容粘贴进来
chmod 600 ~/.ssh/authorized_keys
```

#### 1.5.3 配置Nginx（HTTPS）
```bash
sudo vim /etc/nginx/conf.d/blog.conf

server {
    listen 443 ssl http2;
    server_name 你的域名.com;
    
    ssl_certificate /etc/nginx/ssl/你的域名.pem;
    ssl_certificate_key /etc/nginx/ssl/你的域名.key;
    
    root /var/www/blog;
    index index.html;
    # ... 其他配置同上
}

# 80 跳转到 443
server {
    listen 80;
    server_name 你的域名.com;
    return 301 https://$host$request_uri;
}
```

#### 1.5.4 Hexo 配置
```bash
deploy:
  - type: git
    repo: username@你的服务器IP:/var/repo/blog.git
    # repo: ssh://username@你的服务器IP:port/var/repo/blog.git
    branch: master
```
